Qué esWhat it is

Un laboratorio para responder una pregunta concreta: ¿cuánto se puede confiar en un revisor de código con IA? Todo lo que se afirma aquí viene con su muestra, su intervalo y lo que no se puede concluir.A lab to answer one concrete question: how far can you trust an AI code reviewer? Everything claimed here comes with its sample, its interval and what cannot be concluded.

Una skillA skill

Para Claude Code: revisa por tipo de archivo, valida con un script lo que devuelve el modelo y registra qué decide una persona con cada hallazgo.For Claude Code: it reviews by file type, validates the model output with a script and records what a person decides about each finding.

Bancos de pruebasBenchmarks

Módulos ficticios con defectos plantados y respuesta conocida, y una puntuación automática, sin juicio humano.Fictional modules with planted defects and a known answer, scored automatically with no human judgement.

Una guíaA guide

La rúbrica, el registro de hallazgos, cómo se arma un banco y cómo se decide una fase de despliegue.The rubric, the findings ledger, how a benchmark is built and how a rollout phase is decided.

ResultadosResults

Un modelo, un etiquetador y muestras pequeñas: es un piloto, no una calibración.One model, one labeller and small samples: this is a pilot, not a calibration.

PruébaloTry it

Hace falta Node 20 o superior y Python 3.12.You need Node 20 or later and Python 3.12.

git clone https://github.com/osworky/ai-code-review-lab.git
cd ai-code-review-lab
python -m unittest discover -s tests
cd skills/ai-code-review && npm install && npm test

Para instalar la skill en Claude Code, copia skills/ai-code-review/ a ~/.claude/skills/ai-code-review/ y pide «revisa esta rama con ai-code-review».To install the skill in Claude Code, copy skills/ai-code-review/ to ~/.claude/skills/ai-code-review/ and ask «review this branch with ai-code-review».

Lo que no se puede afirmarWhat cannot be claimed

  • Que el revisor acierte por categoría de la rúbrica: las etiquetas no la llevan y falta la clase negativa.That the reviewer is right per rubric category: the labels carry none and the negative class is missing.
  • Que detecte defectos de omisión o de interfaz: en el piloto no vio ninguno de los de la API.That it detects omission or interface defects: in the pilot it found none of the API ones.
  • Que sirva para subir de fase: ninguna de las 6 categorías llega al mínimo de 30 filas.That it is ready to move up a phase: none of the 6 categories reaches the 30-row minimum.
  • Nada sobre otros modelos ni otros etiquetadores.Anything about other models or other labellers.
