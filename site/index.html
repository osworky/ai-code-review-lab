Carril 1 · Revisión de código con IALane 1 · Code review with AI

  1. 1

    Plantar defectosPlant defects

    Se escribe un golden dataset (respuesta conocida) con defectos y señuelos inofensivos en un banco de pruebas, antes de ejecutar nada.A golden dataset (known answer) of defects and harmless decoys is written into a benchmark before anything runs.

    18 defectos · 6 señuelos18 defects · 6 decoys

  2. 2

    RevisarReview

    La skill revisa con foco por tipo de archivo. Se repite en varias corridas y se compara con un control sin foco.The skill reviews with per-file-type focus. It is repeated over several runs and compared with a control without focus.

    3 corridas + 1 control3 runs + 1 control

  3. 3

    ValidarValidate

    Un validador determinista rechaza lo que no cumple el esquema o cita líneas fuera del diff. No usa un modelo.A deterministic validator rejects output that breaks the schema or cites lines outside the diff. It uses no model.

  4. 4

    EtiquetarLabel

    Una persona decide cada hallazgo con una etiqueta A / M / R y queda en el registro (ledger).A person decides every finding with an A / M / R label and it goes into the ledger.

    63 hallazgos etiquetados63 labelled findings

  5. 5

    MedirMeasure

    Se calculan precisión, recall y ruido, cada una con su intervalo de Wilson. Si la prueba es demasiado fácil aparece el efecto techo.precision, recall and noise are computed, each with its Wilson interval. If the test is too easy a ceiling effect shows up.

    precisión amplia 79 % (68–88 %)broad precision 79 % (68–88 %)

  6. 6

    DecidirDecide

    Un Go / No-Go con criterios fijados de antemano. Mientras no haya datos, el revisor se queda en fase consultiva y no es un quality gate.A Go / No-Go with criteria fixed in advance. Until the data is there, the reviewer stays advisory and is not a quality gate.

    0 de 6 categorías con 30 filas: No-Go0 of 6 categories with 30 rows: No-Go

Carril 2 · Pruebas del proyecto realLane 2 · Testing of the real project

  1. 1

    ContratosContracts

    Las reglas del negocio se escriben como contratos que firma el responsable. «Sin contrato, no hay test».Business rules are written as contracts signed by the owner. “No contract, no test.”

    30 contratos30 contracts

  2. 2

    SuitesSuites

    Pruebas de extremo a extremo con Playwright y pruebas unitarias sobre el sitio real.End-to-end tests with Playwright and unit tests over the real site.

    32 flujos E2E (27 automatizados) · 140 pruebas Playwright · ~730 unitarias32 E2E flows (27 automated) · 140 Playwright tests · ~730 unit

  3. 3

    MutaciónMutation

    Con mutation testing se mide si los tests detectan cambios; los mutantes equivalentes sin revisar hacen de la cifra un piso.mutation testing measures whether the tests catch changes; unreviewed equivalent mutants make the figure a floor.

    84,09 % → 95,17 %84.09 % → 95.17 %

  4. 4

    Red teamRed team

    Un agente aparte hace red teaming sobre la API con pruebas adversariales, que encuentran defectos de omisión.A separate agent does red teaming on the API with adversarial tests, which find omission defects.

    46 pruebas · 18 detectan un defecto · 13 reales cerrados46 tests · 18 catch a defect · 13 real ones closed

  5. 5

    SobrevivientesSurvivors

    Cada mutante que sobrevive se clasifica. Sin contrato no se escribe test: vuelve al catálogo como modo de falla.Every surviving mutant is classified. With no contract no test is written: it goes back to the catalogue as a failure mode.

    144 sobrevivientes → 29 tests nuevos · 7 modos de falla144 survivors → 29 new tests · 7 failure modes

Tres nivelesThree levels

1 · Rúbrica y guía1 · Rubric and guide

Criterios de revisión y catálogo de modos de falla. Se aplica sin instalar nada.Review criteria and a catalogue of failure modes. It applies without installing anything.

2 · Medir2 · Measure

Bancos con respuesta conocida, puntuados sin juicio humano, e intervalos de Wilson.Benchmarks with a known answer, scored with no human judgement, and Wilson intervals.

3 · La skill completa3 · The full skill

Para Claude Code: revisa por tipo de archivo, valida la salida con un script y registra la decisión de una persona.For Claude Code: reviews by file type, validates the output with a script and records a person's decision.

cd ai-code-review-lab
python -m unittest discover -s tests
cd skills/ai-code-review && npm install && npm test

Lo que no se puede afirmarWhat cannot be claimed

  • Que el revisor acierte por categoría de la rúbrica: las etiquetas no la llevan y falta la clase negativa.That the reviewer is right per rubric category: the labels carry none and the negative class is missing.
  • Que detecte defectos de omisión o de interfaz: en el piloto no vio ninguno de los de la API.That it detects omission or interface defects: in the pilot it found none of the API ones.
  • Que sirva para subir de fase: ninguna de las 6 categorías llega al mínimo de 30 filas.That it is ready to move up a phase: none of the 6 categories reaches the 30-row minimum.
  • Nada sobre otros modelos ni otros etiquetadores.Anything about other models or other labellers.
